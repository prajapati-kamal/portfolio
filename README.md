## 🚀 One-Click Deployment Guide

This repository has `index.html` at the root, making it 100% plug-and-play for free hosting platforms:

### 1. GitHub Pages (Recommended)
1. Push this repository to your GitHub account (e.g. `prajapati-kamal/portfolio` or `prajapati-kamal.github.io`).
2. Go to **Repository Settings** -> **Pages** (on the left sidebar).
3. Under **Branch**, select `main` and folder `/ (root)`.
4. Click **Save**. Your website will be live in ~60 seconds at:
   `https://prajapati-kamal.github.io/portfolio` (or `https://prajapati-kamal.github.io`)

### 2. Vercel
1. Go to [vercel.com](https://vercel.com) and click **Add New Project**.
2. Import this GitHub repository.
3. Click **Deploy**. Vercel will automatically detect static files and deploy in seconds!

### 3. Netlify
1. Go to [netlify.com](https://netlify.com) and click **Add new site** -> **Import an existing project**.
2. Connect your GitHub repository.
3. Leave build settings default and click **Deploy Site**.

## 🛠️ Local Development & Testing

### Option 1: Double-Click `index.html`
Simply double-click `index.html` to open it directly in Google Chrome, Microsoft Edge, or Firefox.

### Option 2: Run Local Python Server
```bash
python -m http.server 8000
```
Then visit [http://localhost:8000](http://localhost:8000) in your browser.
