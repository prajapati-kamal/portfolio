# Portfolio

This repository contains a professional portfolio site for Kamal Prajapati.

Stack: Next.js + Tailwind CSS + Framer Motion

Branch: portfolio-site (initial scaffold)

How to run locally:

1. npm install
2. npm run dev

I scaffolded an initial one-page layout with Hero, About, Projects, Skills, and Contact sections. Review the portfolio-site branch and let me know any content or style changes; I can open a PR or deploy to Vercel when you want.
